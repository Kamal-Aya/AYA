Offizielle Website des **Assalam Görlitzer interkultureller Verein e.V.** in Görlitz, Sachsen.

## Über den Verein

Der Assalam Görlitzer interkultureller Verein e.V. ist ein gemeinnütziger Verein in Görlitz, der sich für **interkulturelle Begegnung**, **islamische Gemeinschaft** und **Integration** einsetzt. Wir bieten:

- Gebetsräume für die muslimische Gemeinde
- Deutschkurse für Anfänger und Fortgeschrittene
- Arabisch-Unterricht für Kinder
- Hilfe bei Behördenangelegenheiten und Formularen
- Kulturelle Ausflüge und Veranstaltungen
- Besuche für Schulklassen und interessierte Gruppen

## Website-Funktionen

| Feature | Beschreibung |
|---------|-------------|
| **Mehrsprachig** | Deutsch, Englisch, Arabisch, Persisch (Farsi) |
| **Gebetszeiten** | Tägliche Zeiten aus `times_2026_gorlitz.json` mit Hijri-Datum |
| **Jumu'a** | Freitagsgebet um 14:00 Uhr |
| **Aktivitäten** | Verwaltung über externe JSON-Dateien |
| **Events** | Kommende Veranstaltungen aus `events.json` |
| **Kontaktformular** | Direkte E-Mail-Anfragen |
| **Responsive** | Optimiert für Mobile, Tablet und Desktop |
